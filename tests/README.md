# Tests (optional, for developers)

Repack Pilot itself needs no Node.js, npm or build step. These scripts are the checks behind the acceptance checklist in `TECH_NOTES.md` §12. Run them after changing code or data. GitHub Actions runs them on every push and pull request (`.github/workflows/tests.yml`).

The suites grow with the milestones, as in Rebate Hunter: `engine`, `sims` and `layout` arrived with the engine and the night simulation (M2); the scripted replay joined `sims` and the `live` suite arrived with the agent (M3); all six scenarios joined `sims` and `live`, and `accept` arrived with the scenarios (M4), with the Customer view's cases in `smoke` and `layout` (`TECH_NOTES.md` D62–D69); `page-icon`, `vici-files` and `hexagon` arrived with the move to Vici (0.5.0, D70–D83), and `tokens` runs `tests/tokens.mjs` since then; `design` follows with the hardening (M5).

`node tests/run-all.mjs` runs everything in that order and prints a summary. Name suites to run only those (`node tests/run-all.mjs unit smoke`); name cases to run only those within a suite (`node tests/smoke.mjs modes diag`; in the layout suite a size, `1280x720`, or the Customer view at a size, `customer-1280x720`).

No test calls a real API or spends money: api.anthropic.com is answered by a stand-in or the fake Claude inside the browser. The app loads nothing else from outside (no CDN, no tiles), and the suites block any other request and fail on one.

## Setup for the browser suites

You need Node.js 20 or later and Playwright with Chromium. Install them once, outside this folder:

```
npm install -g playwright@1.56.0
npx playwright install chromium
```

The GitHub Actions workflow pins the same version, the one the suites were last run with.

Then run with Node's module path pointing at the global packages:

```
NODE_PATH="$(npm root -g)" node tests/run-all.mjs
```

On Windows PowerShell: `$env:NODE_PATH = (npm root -g); node tests/run-all.mjs`.

Options (environment variables):
- `PLAYWRIGHT_MODULE`: path to a Playwright installation, instead of `NODE_PATH`.
- `CHROME_PATH`: use this Chrome or Chromium binary instead of Playwright's.
- `RP_TEST_OUT`: folder for screenshots, downloads and result files (default: the system temp folder, `repack-pilot-tests/`).

The suites serve the app on `127.0.0.1`: smoke on port 8865, sims on 8866, layout on 8867, live on 8868, accept on 8869 (Rebate Hunter's use 8765 to 8770, so both can run side by side); the hexagon suite takes a random one between 8790 and 9089.
